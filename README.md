# Traker - React Frontend Developer Assignment (Indian Mobility Edition)

A clean, responsive admin dashboard built for ride-booking and urban mobility platforms, tailored specifically for Indian operations (covering major cities like Bengaluru, Mumbai, Delhi, and Hyderabad).

## 🚀 Live Demo & Repository
- **GitHub Repository**: https://github.com/rahulpaswan40/traker-react-admin-dashboard
- **Live Vercel Deployment**: https://traker-react-admin-dashboard.vercel.app/

---

## 📋 Project Overview
Traker is a frontend-only admin web application designed to track, manage, and monitor ride-booking operations[span_0](start_span)[span_0](end_span). It provides real-time metric visibility, ride management, detailed customer/driver tracking, and comprehensive filtering capabilities with a modern, clutter-free user interface[span_1](start_span)[span_1](end_span).

---

## 🛠 Tech Stack
- **Core Framework**: React 18 / JavaScript (with modular component architecture)[span_2](start_span)[span_2](end_span)
- **Routing**: React Router v6 for smooth client-side navigation[span_3](start_span)[span_3](end_span)
- **State Management**: React Context API & custom hooks for local state and theme handling[span_4](start_span)[span_4](end_span)
- **Build Tool**: Vite for ultra-fast bundling and development server[span_5](start_span)[span_5](end_span)
- **Styling**: Vanilla CSS with custom properties, responsive layouts, and clean UI components[span_6](start_span)[span_6](end_span)

---

## ✨ Key Features Implemented
1. **Executive Dashboard**:
   - Real-time KPI metrics tracking Total Rides, Completed/Cancelled trips, Active Drivers, Customers, and Gross Revenue (in ₹ INR)[span_7](start_span)[span_7](end_span).
   - Interactive statistics switcher (Today, Last 7 Days, Last 30 Days) with dynamic visual trends[span_8](start_span)[span_8](end_span).
2. **Ride Management & Filtering**:
   - Comprehensive ride listing containing Ride IDs, Customer/Driver info, vehicle types, route locations, itemized fares, and visual status badges (`Completed`, `Ongoing`, `Cancelled`, `Pending`)[span_9](start_span)[span_9](end_span).
   - Instant search by ID, customer name, or driver name along with multi-attribute filtering without page refreshes[span_10](start_span)[span_10](end_span).
3. **Driver Directory**:
   - Complete fleet overview with ratings, vehicle numbers, online/offline status, and quick-view detail dialogs[span_11](start_span)[span_11](end_span).
4. **Responsive UI/UX**:
   - Structured desktop sidebar layout that gracefully adapts into mobile drawers for smaller screens, alongside light/dark theme toggle support[span_12](start_span)[span_12](end_span).
